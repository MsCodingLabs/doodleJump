# 🟡 Doodle Jump – Classic Jumping Game in the Browser

A fun, fast-paced, and addictive jumping game, now available in your browser! Inspired by the mobile classic, *Doodle Jump*, this browser version lets you bounce from platform to platform, dodge obstacles, and chase high scores. The goal: jump as high as you can, avoid enemies, and aim for the top!
