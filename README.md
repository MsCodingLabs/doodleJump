# 🟡 Doodle Jump – Classic Jumping Game in the Browser

**Bounce, dodge, and climb! A tribute to the addictive mobile classic.**

Originally a simple concept, *Doodle Jump* became a mobile gaming phenomenon thanks to its endless, high-score-chasing fun. Now you can play a browser-based version built with web technologies.

## 🕹️ Gameplay

Jump from platform to platform, avoid enemies and obstacles, and aim for the highest score possible. One wrong move – and you fall!

## ✨ Features

- Infinite vertical jumping mechanic
- Random platform generation
- Moving and disappearing platforms
- Score tracking and display
- Playable in any modern browser

## 🛠️ Built With

- HTML
- CSS
- JavaScript

## 📁 How to Play

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Use your keyboard to control the jumper and reach new heights!
